2. Code Tour & Route Stops

The 3 critical files that deliver the kernel and protect against runtime drift:

Stop 1: Calendar Generator & RFC 5545 Compliance — src/utils/ics.ts

Pure client-side RFC 5545 string builder. Implements CRLF (\r\n) line breaks, VCALENDAR wrapping, text escaping, and all-day VALUE=DATE format.

Key function: buildIcsContent(events: CalendarEvent[])

Stop 2: Backend Prompt Anchoring & Zod Validation — server.ts

Receives client notes + anchor timestamp. Passes current time to the AI prompt so "tomorrow" and "Friday" calculate deterministically. Validates the output with Zod before returning.

Key endpoints: POST /api/process and fallback rule parser extractWithRuleEngine()

Stop 3: Interactive Dashboard & State Coordination — src/App.tsx

Coordinates user interactions, sample loader, dual-route failover, Markdown checklist copying, and single/batch .ics downloads.

Key handler: handleProcessNotes()

3. "To Change This, Start Here"

  • To modify default meeting lengths or deadline prefixes: Look in server.ts > extractWithRuleEngine and the system prompt under POST /api/process.
  • To tweak calendar output properties (alarms, reminders): Look in src/utils/ics.ts > buildIcsContent.
  • To adjust the dark UI aesthetic or color accents: Look in tailwind.config.js and individual component classes in src/components/.

4. A Practice to Reuse: Spec-Driven Verification Before UI

What we did: Before scaffolding the React UI or hooking up API routes, we isolated the unique kernel (RFC 5545 calendar file generation) into a standalone module (src/utils/ics.ts) and wrote an automated unit test suite (tests/ics.test.ts) that verified 27 strict assertions (CRLF endings, character escaping, all-day formatting).

Why it worked: Separating the format-critical calendar kernel from the UI prevented prompt drift and styling distractions. When the UI was built in Slice 3, the underlying calendar export was already 100% verified and guaranteed to work in native calendar applications without debugging during the demo.
